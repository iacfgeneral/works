# works

연구행정 업무를 브라우저에서 바로 처리할 수 있는 작은 도구 모음입니다. 별도의 서버나 빌드 과정 없이 각 폴더의 `index.html`을 열어 사용할 수 있습니다.

## 도구

### [연구인력 월별 인건비 검증](./연구인력%20월별%20인건비%20검증/index.html)

`contractsubject`, `joinlist`, `ingcontract`, `currentemp` 엑셀 파일을 비교해 월별 인건비의 일치 여부와 누락 정보를 확인합니다. 검증 결과는 CSV 또는 XLSX로 내려받을 수 있습니다.

### [과제별 계약종료 대상자](./과제별%20계약종료%20대상자/index.html)

참여 이력이 담긴 엑셀 파일을 읽어 직번·성명·과제번호 기준으로 그룹화하고, 선택한 년월에 계약이 종료되는 대상자를 추출합니다. 결과는 XLSX 파일로 내려받을 수 있습니다.

## 사용 방법

1. 저장소 루트의 [`index.html`](./index.html)을 열고 사용할 도구를 선택합니다.
2. 도구 화면에서 안내된 형식의 `.xlsx` 또는 `.xls` 파일을 업로드합니다.
3. 검증 또는 추출을 실행하고 필요한 경우 결과 파일을 다운로드합니다.

로컬 파일로 직접 열거나 정적 호스팅으로 제공할 수 있습니다. 브라우저 보안 정책으로 직접 열기가 제한되는 환경에서는 저장소 루트에서 간단한 정적 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

그 다음 <http://localhost:8000>에 접속합니다.

## 데이터 처리 및 개인정보

엑셀 파일은 각 도구의 브라우저 안에서 처리되며 별도 업로드 서버로 전송되지 않습니다. 민감한 원본 파일은 공용 컴퓨터나 공유 브라우저에 남기지 말고, 작업이 끝난 뒤 다운로드 파일과 브라우저 기록을 확인하세요.
